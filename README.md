# Sem5 Labs

Repository for semester 5 lab work across cryptography, algorithms, web technology, and statistical analysis exercises.

## Repository Layout

### Cryptography_Labs
Core cipher and number-theory exercises, grouped by lab:

- Lab 1: `CaesarCipher.py`, `HillCipher.py`
- Lab 2: `PlayFairCipher.py`, `VigenereCipher.py`
- Lab 3: `RailFenceCipher.py`
- Lab 4: `DES.py`
- Lab 5: `additive_inverse.py`, `multiplicative_inverse.py`, `relatively_prime.py`
- Lab 6: `AES.ipynb`, `CBC.ipynb`
- Lab 7: `miller_rabin.py`, `primitive_root.py`, `totient_function.py`
- Lab 8: `diffie_hellman.py`, `elgamal.py`, `rsa.py`
- Lab 9: `md5_hash.py`, `sha_hash.py`

### DAA_Labs
Design and Analysis of Algorithms programs:

- Lab 1: sorting implementations in `Sort.cpp`
- Lab 2: `Sort2.cpp`
- Lab 3: `FractionalKnapSack.cpp`, `HeapSort.cpp`, `JobSequencing.cpp`
- Lab 4: `DijkstraAlgorithm.cpp`, `KruskalAlgorithm.cpp`, `PrimAlgorithm.cpp`
- Lab 5: `Floyd_Warshall.cpp`, `zero_One_Knapsack.cpp`

### SAM_Labs
Statistical analysis and testing exercises:

- Lab 1: `Q1_Q2.cpp`, `Q3.cpp`, `Q4.cpp`, `Q5.cpp`, `Q6.cpp`, `sam5.cpp`
- Lab 2: `Q1.cpp`, `Q2.cpp`, `Q3.cpp`
- Lab 3: `Q1.cpp`, `Q2.cpp`, `Q3.cpp`
- Lab 4: `Q1autocorrelation.cpp`, `Q2PokerTest.cpp`
- Lab 5: `AutoCorrelationTest.cpp`, `ChiSquareTest.cpp`, `KolmogorovSmirnovTest.cpp`, `MarkovChain.cpp`, `PokerTest.cpp`

### WebTech_Labs
HTML, CSS, and PHP practice pages:

- Lab 1: basic static HTML pages in `Q1Simple.html` through `Q5Destination.html`
- Lab 2: `home.html`, `index.html`
- Lab 3: `Q1index.html`, `Q1styles.css`, `Q2PrjTableDiv.html`, `Q3form.html`, `Q3styles.css`
- Lab 4: `Q1_StudentInfo.html`, `Q2_tablePattern.html`, `Q3_fibonacci.html`, `Q4_student_array.html`
- Lab 5: `Q1.html` through `Q5.html`
- Lab 6: `Q1.php` through `Q5.php`
- Lab 7: `Q1_CRUD.php` through `Q8_StaticMembers.php`

### output
Generated outputs for the lab programs. These files are derived artifacts and can be recreated from the source labs.
